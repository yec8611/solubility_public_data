# Public mini-protein data card — 2026-11-08

This is a training/evaluation package for insolubility prediction on released canonical/core sequences of 20–100 amino acids, screened to remove identifiable antibody variable domains and source-annotated antibodies. It combines natural small proteins and designed monomers; it does not assert that every sequence is an independently verified folded mini-protein. Short/constant immunoglobulin fragments can evade the available screen.

The training table contains 1,686 PSI records, 368 insoluble and 1,318 soluble, in737 families. The separate retrospective panels are Garcia284 (44 positive), NESG152 (32 positive), and eSOL198. eSOL includes151 strict binary extremes (24 positive) and47 intermediate or boundary measurements used only for continuous evaluation. There are no exact training/external sequence or family overlaps under the retained assignments. External panels are distinct assay domains, not exchangeable random replicates.

The frozen public record IDs and ordered feature caches came from the earlier study. The primary export script validates descriptors against the original matrices and retains the original five-seed random/grouped split memberships. Family grouping used40% identity,80% bidirectional coverage, and construct aliases. The group files are supplied; grouping is not recomputed by this package. Provenance hashes identify the released record files. Pretraining overlap with ESM's protein corpus was not audited.

`insoluble=1` reverses the source `binary_soluble` field for PSI/Garcia/NESG. Garcia concerns soluble expression conditional on expression; PSI/NESG reflect source-specific expression/solubility protocols. eSOL measures cell-free soluble fraction in the PURE system, not the same endpoint as cellular expression. eSOL fractions above1 are retained as original measurement values rather than clipped. Its binary rule is `<0.30` positive, `>0.70` negative; boundaries and intermediate values are unclassified. Solubility fraction and source annotations must never be predictors.

Sequence preprocessing can remove or normalize construct aliases, so the miniprotein length constraint is about the canonical/core sequence. Common assay tags or flanks can make the complete measured construct longer than100 aa. Exact full constructs, pH, concentration, buffer and replicate details are not uniformly available. Missing assay metadata are unknown, not zeros. Generalization to a new internal synthesis/assay pipeline is not established by these public results.

All source panels have prior benchmark exposure. This package does not claim a fresh blinded test, a universal operating threshold, or superiority over the historical ESM650 models. Validation runs bundled with the package are capped software smoke checks. Five repeated holdouts share observations; their mean/SD describes training/split sensitivity, not five independent population samples. Source-wise external results should remain separate.

Rows are distributed as plain XLSX (`Records`, `Sources` sheets) and parity-checked JSON. No source annotation is used as a feature. Internal experimental data and the mixed-license weak pool are omitted from the public release. See [DATA_LICENSES.md](../DATA_LICENSES.md) for attribution, changes and rights.
