# solubility_public_data

Public mini-protein insolubility package. The initial complete implementation is available on the [package-20261108 branch](https://github.com/yec8611/solubility_public_data/tree/package-20261108) and its pull request, pending review.

```bash
git clone --branch package-20261108 https://github.com/yec8611/solubility_public_data.git
```

The package contains residual fusion MLP and BiLSTM architectures, 1,686 training proteins, 634 external evaluation proteins, XLSX data, reproducible scripts/notebooks and training instructions. See the branch README for setup and the release for frozen ESM650 input embeddings.
